# Hello, World!

What is the first thing you'd learn when learning programming? That's correct! You'll probably learn about printing "Hello World". In other words, printing is the "Hello World" of programming.

That makes me wonder what would be the "Hello World" of other aspects, or what would be the very first basic step of a concept or skill. Here is my opinion on what the "Hello World" of some fields would be.

## Common:
| Field | The Hello World |
| --- | --- |
| Programming | printing `"Hello, World!"` |
| Machine Learning | recognizing handwritten digits |
| Math | counting from 1 to 10 |
| Construction |  |
| Blender (art program) | Donut |
| Music theory | C major scale |
| Piano piece | Canon in D |

## Less common:
| Field | The Hello World |
| --- | --- |
| Mathematician proof | The proof is left as an exercise for the reader.  |
| Git | `git add . && git commit -m "Initial commit"` |
| Jokes | why did the chicken cross the road? |
| Meme music | rickroll |
| Furry | boykisser |
| Juggling | 3-ball-cascade |
| Posting meme video on YouTube | bad apple |

## Absurd:
| Field | The Hello World |
| --- | --- |
| `n` | `n - 1` |
| Chess | e4 |
